# Açaí do Fessão — Catálogo Online

Catálogo digital desenvolvido para **Açaí do Fessão**, onde os clientes podem montar o próprio açaí, escolher complementos, forma de entrega e pagamento, e enviar o pedido diretamente pelo **WhatsApp**.

🔗 **Projeto online:** [https://acai-catalog.vercel.app/](https://acai-catalog.vercel.app/)

## Funcionalidades

* Escolha do tamanho do açaí
* Seleção de creme
* Escolha de complementos
* Cálculo automático do valor do pedido
* Campo para observações
* Possibilidade de adicionar mais de um açaí
* Escolha entre entrega ou retirada
* Seleção da forma de pagamento
* Envio do pedido diretamente para o WhatsApp
* Layout responsivo

## Tecnologias

* Next.js
* TypeScript
* Tailwind CSS
* Vercel

## Como rodar

git clone [https://github.com/JefersonPinho/acai-catalogo-app.git](https://github.com/JefersonPinho/acai-catalogo-app.git)

cd acai-catalogo-app

npm install

npm run dev

Depois acesse:

[http://localhost:3000](http://localhost:3000)

## Sobre

Projeto desenvolvido para uso real no **Açaí do Fessão**, com o objetivo de facilitar e organizar os pedidos dos clientes através do WhatsApp.
